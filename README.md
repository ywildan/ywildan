## 🌟 Featured Project: StudentLab

> **A web-based laboratory management system** built to streamline academic lab operations. From scheduling equipment usage to tracking student assignments and generating reports — all in one place.

- **Tech Stack**: TypeScript, Next.js, Node.js, PostgreSQL, Prisma, Docker
- **Key Features**:
  - Role-based access control (Admin, Lecturer, Assistant, Student)
  - Real-time lab schedule management
  - Automated reporting and analytics dashboard
- **What I learned from this project**:
  - Implementing complex database relationships (normalization & indexing)
  - Designing a modular and testable RESTful API
  - Managing containerized deployment with Docker Compose
  - Writing comprehensive unit and integration tests
